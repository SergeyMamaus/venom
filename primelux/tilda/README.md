# PrimeLux Hair — установка в Tilda

Сайт теперь только на английском языке и состоит из двух страниц:

- `/en` — главная страница;
- `/blog` — английский SEO-блог.

## Главная страница

Создайте страницу Tilda с адресом `en`, добавьте один блок T123 и вставьте **содержимое** файла `en.html` целиком. Не вставляйте текст `primelux/tilda/en.html` — это имя файла.

## Блог

Создайте вторую страницу Tilda с адресом `blog`, добавьте один блок T123 и вставьте содержимое `blog.html` целиком. Главная и блог уже перелинкованы адресами `/en` и `/blog`.

## Ежедневная публикация через Claude

Файл `../blog/posts.js` является журналом статей. Новую статью нужно добавлять первым объектом в массив `PRIMELUX_POSTS`, после чего обновлять T123-код страницы блога и публиковать страницу Tilda. Каждая карточка автоматически получает CTA на `/en#order`.

Tilda не предоставляет Claude доступ к проекту сама по себе. Для полностью автоматической ежедневной публикации потребуются API/автоматизация и доступы к аккаунту Tilda. Без этого безопасный процесс такой: Claude готовит новый объект статьи, владелец вставляет обновлённый `blog.html` в T123 и нажимает «Опубликовать».

## Ссылки с обычных блоков Tilda

В любой кнопке обычного блока Tilda укажите `/blog` для перехода в блог или `/en` для возврата на главную. HTML-страница и страница из обычных блоков связываются обычными опубликованными URL.

## Заявки

Квиз сохраняет заполненный B2B-бриф в `localStorage` под ключом `primelux-last-brief`. Для отправки менеджеру необходимо подключить реальный CRM/webhook endpoint.
